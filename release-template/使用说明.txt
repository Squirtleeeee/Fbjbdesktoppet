菲比桌宠 — 快速上手
====================

1. 双击「启动菲比.bat」或「菲比桌宠.exe」
2. 桌宠出现在桌面右下角，托盘区有图标
3. 保持桌宠运行，它会监听 127.0.0.1:9527

连接 Claude Code / Cursor
-------------------------
解压目录下的 hooks 文件夹里有 Hook 脚本与配置示例。
请阅读 hooks/README.txt 按步骤配置。

常用操作
--------
- 左键拖拽：移动菲比
- 右键：菜单（Token 统计 / 工作流 / 置顶 / 缩放）
- 滚轮：缩放
- 关闭窗口：最小化到托盘（托盘右键可退出）
